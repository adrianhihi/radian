# Stock quote assets (Robinhood Chain mainnet)

Generated by `node script/gen-stock-quotes.mjs` from Robinhood's registry (`api.robinhood.com/rhj/assets`)
and delayed Yahoo reference prices. **Not executed.** Executing these batches makes every canonical
Robinhood stock token an approved quote asset on the mainnet factory, which needs the legal read on
tokenized stocks first (MAINNET_RUNBOOK.md 5f).

Before executing:
1. Regenerate (prices move): `node script/gen-stock-quotes.mjs`.
2. Review `prices-used.csv`: the symbol → Yahoo ticker mapping is naive; anything with a strange price
   or a multiplier other than 1 must be checked by hand and removed from the batch if wrong.
3. Upload `approve-stocks-01.json` … in the Safe's Transaction Builder (7 batches, 30 tokens each,
   2 calls per token: `setPairTokenEconomics` then `setPairTokenApproved`).
4. Paste `web-quoteAssets.ts.txt` into `web/lib/networks.ts` → `robinhood.quoteAssets` (the price
   route's allow-list must include every `refSymbol`) and `indexer-QUOTE_ASSETS_JSON.txt` into the
   mainnet indexer's `QUOTE_ASSETS_JSON`.

Economics mirror the USDG pair: 4,000 / 10,000 USD expressed in shares at generation time, adjusted by
the token's ERC-8056 multiplier. A stock that splits later keeps its raw-unit thresholds; regenerate and
re-set economics for it if that matters.
